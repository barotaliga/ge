A game's engine source release may carry only its multiplayer game program, where the
single-player monsters remove themselves at spawn, so a reader sent there answers "open" for any
single-player monster. Name the release that carries the single-player program in the first
brief (the porting notes say which), and keep the engine release for the move step and physics.
