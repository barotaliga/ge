=== mistakes
sett a 1
set
exec
inc
cycle x
bind
bind nokey x
bind -nomode a x
alias 9x y
---
unknown command 'sett' (did you mean 'set'?)
set needs a name and a value (write `set <name> <value>`)
exec needs a file (write `exec <name>.cfg`)
inc needs a cvar (write `inc <name> [<by>]`)
cycle needs a cvar and values (write `cycle <name> <v1> <v2>`)
bind needs a key (write `bind <key>`; key names are in docs/console.md)
'nokey' is not a key (use a key's name (a, f1, space, mouse1, mwheelup, pad_a, ctrl+s): docs/console.md)
'-nomode' is not a bind mode (use -game, -console, -menu or -demo)
'9x' is not an alias name (use 1-63 of a-z 0-9 _ + - . )
