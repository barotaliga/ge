---
type: Fixed
title: Quake II servers you join hand over every file the level needs, their commands run, and pause stops a demo
---

Joining a Quake II server that has files you lack now fetches all of them in the original order: the map and models, then the skins inside the models, the sounds, the pictures, each player's model, weapons, skin and icon, the sky, and last the map's wall textures. Commands the server sends you (a setting put back, a mod's binds) now run in your console as if you typed them, unless you filter them with cl_ignore_stufftext. Typing pause while a demo plays stops it where it is, and typing it again plays on.
