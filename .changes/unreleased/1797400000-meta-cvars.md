title: Meta-cvars, and sv_modern
---

A meta-cvar is a cvar whose levels set groups of others, declared in code (`Cvars::add_meta`) or in a cfg (`meta <name> <level> "<name> <value>; ..."`). A value a cfg, the console or the command line set keeps its value whatever order it ran in; turning a meta off puts its members back to what the layers under it say; a level may include another meta's level, and a loop of includes is refused, named. `help`, `cvarlist` and a server's `--explain` name the meta behind every value it set, and `cfg_save` writes the player's own value, never a meta's. The first is `sv_modern`: 1 a modern server (`sv_fps 120`, `sv_maxupdaterate 120`, `sv_rewindmax 0.2`), 2 the same on a LAN with no byte cap and a 0.1 s rewind.
