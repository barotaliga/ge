type: Added
title: Select Game and a classic game in its own look throughout
---

Shooter's Edge's main menu opens on SELECT GAME: each classic game by its name's picture, the install of it found last and whether it is the shareware or the full game, ENTER opening it or finding its folder. Once a classic game is loaded its own recordings play behind the menu (`menu_attract`) and ESCAPE watches them, and the console, the HUD's words, DEMOS, JOIN A GAME and SELECT GAME are drawn in the game's own letters over its own console background. The engine gains `ui::sheet_font`, a game's 16 x 16 glyph sheet as a grid font.
