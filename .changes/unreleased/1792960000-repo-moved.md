---
type: Changed
title: The engine's repository is now barotaliga/ge
---

The engine moved to https://github.com/barotaliga/ge. `ge new` and `ge doctor` now point a game repo at the new address (`kEngineRepo`). From the next release, the release assets, `gh -R` commands and the GitHub Packages artifact are at `barotaliga/ge` (`ghcr.io/barotaliga/ge`). The CMake package keeps its name, `find_package(gameengine2)`.
