type: Added
title: The sequel's player commands
---

In the sequel, chat works (`say`, `say_team`, flood protection), a word the game does not know is said as chat, the cheats work where the server allows them (`give`, `god`, `notarget`, `noclip`, behind `cheats` in deathmatch), and `weaplast`, `wave <n>` gestures, `players` and `playerlist` answer as the game does. The keys the install's own config binds (`use Blaster`, `wave 0`, `weapnext`) now reach the game from the window's console.
