type: Added
title: A Quake II server's terminal takes status, kick, say, listmaps and gamemode; every server records on demand
---

The dedicated Quake II server's own console now runs the administrator's commands (`status`, `kick`, the address lists), the rules' (`map`, `gamemap`, settings), `say` (seen by every player as "console: ..."), `listmaps` and `gamemode <dm|coop|sp|?>` for the next map. Every game's dedicated server can record the match on demand: `serverrecord <name>` writes `demos/<name>.ged`, and `serverstop` ends it. In single player, `g_fix_triggered 1` brings in monsters a map left waiting for a trigger that never comes, and `g_commanderbody_nogod 1` lets the tank commander's body be shot apart.
