type: Added
title: One script sets up a Mac
---

`tools/setup-macos.sh` takes a freshly installed Mac to one that builds the engine and runs its tests, gates and labs on its Metal adapter: it installs Homebrew (and with it Xcode's Command Line Tools), puts Homebrew on PATH for new shells, and installs CMake, Ninja, ccache, bash 4+, clang-format and clang-tidy 18, Node.js, Python 3 and gh. It runs on the system's bash 3.2, installs only what is missing, broken or too old, and returns in under a second when nothing is.
