title: A hub's Watch and Demo pages
---

The hub has a Watch page for each broadcast (`/watch/{node}/{stream}`) and a Demo page for each archived demo (`/demo/{sha256}`), which hold the game's web viewer when the hub is started with `--viewer=<dir>`, and say why when it is not. A TV node's status record now names the WebSocket port that browsers connect to.
