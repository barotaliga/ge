type: Added
title: place names in every classic game, kept in recordings and said in chat
---

Every classic game: a place reaches 500 units, place-name files and loose files are found in any
letter case, `.pkz` zips are read, packs of any other name load after the numbered ones by name
and one named with a leading `_` is set aside. A recording keeps the place names it was played
with, so a demo needs no file to show them. `say` and `say_team` fill `%l` with the place you are
in. The sequel adds `$loc_here` and `$loc_there`.
