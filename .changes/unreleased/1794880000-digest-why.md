---
type: Added
title: ge digest <lab> --why names what moved in a lab's digest
---

Every lab run writes `digest.tsv` beside its report: each input its digest hashed, a line each. `ge digest <lab> --why` compares it with the same lab's run at `--base` (default `origin/main`, built in a scratch worktree, or a run kept with `--tag`) and prints what moved: each metric's two values, each table row's cells by column, the rows, metrics, shots and files that came or went, or the same inputs hashed in another order.
