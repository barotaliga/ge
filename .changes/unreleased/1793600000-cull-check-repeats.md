title: The world lab's cull check draws a difference again
---

The `world` lab's cull check draws a still that differs from the unculled one again before it counts it as the cull's: a difference that comes back (or any difference on the software adapter) is a `cull-faults` failure with the view named and the culled, unculled and difference pictures written beside the report; one that does not come back on a hardware adapter is a warning and a measured `cull-unrepeated` count.
