title: The world lab's cull check draws a difference again
---

The `world` lab's cull check draws a still that differs from the unculled one again before it counts it as the cull's: a repeated difference is a `cull-faults` failure with the view named and the culled, unculled and difference pictures written beside the report. On the software adapter any differing pixel counts; on a GPU only one more than four levels off, since two draws of one frame there differ by a level here and there. A difference that does not come back is a warning and a measured `cull-unrepeated` count.
