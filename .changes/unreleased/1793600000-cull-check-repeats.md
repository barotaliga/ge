title: The world lab's cull check draws a difference again
---

The `world` lab's cull check draws a still that differs from the unculled one again before it counts it as the cull's: any difference on the software adapter is a `cull-faults` failure with the view named and the culled, unculled and difference pictures written beside the report; on a hardware adapter a difference never fails: one that comes back is a warning and a measured `cull-hardware` count, one that does not a warning and a measured `cull-unrepeated` count.
