type: Added
title: Labs draw only the shots named with --shots
---

`labs <id> --shots=<id,...>` (and `ge lab <id> --shots=...`) draws only the named shots of a picture lab while one look is iterated: every other picture under `previews/<id>/` and the contact sheet stay as the last whole run wrote them, and a note says what was drawn. A lab skips the render too by asking `lab.wants(id)` before it draws (the `world` lab does: its smoke run drops from about 19 s to 4 s for one view). A named id with no shot fails the run with the ids the lab has. The runner refuses `--shots` beside `--all`, `--check-digests` or `--write-digests`, since such a run's digest is not the lab's.
