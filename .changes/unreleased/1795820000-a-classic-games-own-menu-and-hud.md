---
type: Changed
title: A classic game's own main menu and HUD pictures, with no free-art choice
---

Shooter's Edge's main menu is now the loaded game's own table of pages, and a game says which modes it has (a single-player campaign, multiplayer), both through the game's adapter. With a classic game loaded the HUD always draws that game's own pictures: the `hud_art` cvar and the VIDEO page's HUD PICTURES row are removed, and the game's free art is kept for Shooter's Edge's own content.
