type: Added
title: Load your classic game from the menu
---

Shooter's Edge's OPTIONS ▸ CLASSIC ENHANCED now starts with LOAD GAME: pick the folder your classic game is installed in with the desktop's folder chooser (or `basedir <folder>` in the console) and it is played at once, the multiplayer client's folder over `id1` when the install has one, its packs enhanced in the background (`ce_auto`) with the world drawn again from the cache when the run ends. A folder that is not an install is refused with what it lacks, and the folder loaded is opened again at the next start. ENHANCE shows the run stage by stage. The engine gains `platform::pick_folder` and `Console::remove_command`.
