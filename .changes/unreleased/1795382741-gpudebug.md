---
type: Added
title: gpudebug copies the frame and everything an agent needs to the clipboard
---

Every game window has a `gpudebug [frames]` console command: the console is hidden, the next frames are measured as `gpustats` measures them, and the frame after them is copied to the clipboard as one picture, with a band below it holding the time, the build (commit, uncommitted changes, branch, build type, compiler, system), the frame's size, the game's own notes (the map, where the player stands and looks, a line to draw the same view again) and the GPU's report; the same notes are the copy's text. Nothing is saved. `gpustats` moved into the engine (`engine/render/gpu_watch.hpp`), so Fall Line has both commands too.
