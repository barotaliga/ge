type: Added
title: Quake II's screen size and font, and full-screen modes for every game
---

Quake II's `viewsize` shrinks the view to a centred rectangle with the border tiled, and `scr_font` changes the letters of the status bar, the scoreboard and the inventory. Every game's `vid_fullscreen` now picks a mode from `vid_modelist`, and Alt+Enter goes back to the last one used (`_vid_fullscreen`).
