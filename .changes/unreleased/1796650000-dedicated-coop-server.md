type: Added
title: A dedicated server for co-op
---

`sesv` runs the single-player campaign in co-op when started with `sv_coop 1`: the game folder's own campaign from its start map, with `sv_coopbots` companion bots (0 to 7) playing from the start and `skill`, `sv_friendlyfire` and `sv_friendlypush` as settings. Players who connect join the campaign and are carried from map to map, eight players at most. A co-op game is listed as one: the server info a server browser reads says `coop 1`, `deathmatch 0`, the skill, the map and eight slots.
