---
type: Added
title: The console lists a setting's few values and a game's spellings
---

While a setting is typed in the console, its row now lists the few values it takes, such as `r_look = modern (classic, modern)`. Typed with a space after it, the list becomes those values, each with what it does, and Tab picks one. A game's own name for a setting or command is listed too, marked "alias of" the name it stands for, and the shared name lists the game's spellings.
