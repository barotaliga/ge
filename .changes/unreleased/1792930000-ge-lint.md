title: ge lint runs clang-tidy over what a change reaches
---

`ge lint` runs clang-tidy's bug-finding checks over the files a change reaches and answers with findings. Each finding gives the file:line, the message and the check, and its next step links the check's documentation.

- **What it lints:** by default, every `.cpp` changed since `--base` (default `origin/main`, untracked files included), plus every `.cpp` whose object includes a changed header (Ninja's dependencies). Name files to lint just those, or pass `--all` for every `.cpp`.
- **Which checks:** the repository's `.clang-tidy`, or the bug-finding set when it has none.
- **Duplicates:** a header's finding repeated through each file that includes it is reported once.
