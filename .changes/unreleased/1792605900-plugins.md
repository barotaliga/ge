title: Plugins
---

Plugins: `plugins/<name>/` directories built as `ge::<name>`, each declaring the engine targets and plugins it depends on; the package now publishes `ge::mountain` (the generated ski mountain: `mountain/mapgen/*.hpp`, `mountain/analysis/*.hpp`) and keeps `ge::racing`, whose headers now come from `plugins/racing/` under the same `racing/*.hpp` include spelling.
