title: Quake II's player commands
---

In Quake II, chat works (`say`, `say_team`, flood protection), a word the game does not know is said as chat, the cheats work where the server allows them (`give`, `god`, `notarget`, `noclip`, behind `cheats` in deathmatch), and `weaplast`, `wave <n>` gestures, `players` and `playerlist` answer as the game does.
