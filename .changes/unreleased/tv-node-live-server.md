title: the classic TV node relays a real classic server
---
Late viewers catch up through teleports (a recording's setangle names its player), the scripted
client answers a server's address check, and game packs load in one read instead of byte by
byte. The `se-tv-node` lab gains `--upstream`, `--upstream-password`, `--player` and `--basedir`
to run against a live server.
