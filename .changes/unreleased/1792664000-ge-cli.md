title: The ge command line
---

`ge new` scaffolds a game repo on the engine release it belongs to, `ge skills sync` keeps that repo's engine skills on its pinned release, `ge doctor` holds the repo to the engine's rules (guidance links, skills, the pin, FP flags, sources, diagnostics) and `ge lessons` reads its lessons back; packages ship `bin/ge`, and the lab framework is published as `ge::lab`.
