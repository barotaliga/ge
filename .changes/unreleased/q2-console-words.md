---
type: Added
title: Quake II's own commands from the console
---

In a Quake II game, the console now takes Quake II's own commands (`score`, `inven`, `putaway`, `invnext`, `invuse` and the rest), so the keys its config binds to them work, and TAB no longer opens the first game's scoreboard over it. `cmd <line>` sends any line to the game's rules as your own command.
