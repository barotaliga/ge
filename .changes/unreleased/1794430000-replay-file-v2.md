title: The replay file version 2 and its field codec
---

`engine/replay` gains the replay file version 2 (`.ged`): one binary format for a kept match and a live broadcast, a header, tracks, one-second blocks with sums and keyframes, and a trailer indexing them, so a file cut short reads to its last whole block (`stream.hpp`). Beside it the field codec (`codec.hpp`): an adaptive binary range coder that writes the same bytes everywhere, with integer and byte models a game writes its predicted fields' residuals through. Shooter's Edge packs its classic recordings into it and back byte for byte (`client/demo_v2.hpp`), a 20-minute 4on4 at half the size of its packed demo. The `replay-codec` lab measures it on any recordings.
