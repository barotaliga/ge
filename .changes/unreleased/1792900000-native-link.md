type: Added
title: Shooter's Edge joins its own server through the engine's node
---

A tunnel (`engine/net/tunnel.hpp`) carries any game's own datagrams inside the engine's node, beside the plain ones on one port. Shooter's Edge's window joins a QuakeWorld server of ours through it (`sv_native`, `cl_native`) while classic clients play on the same port, and falls back to the classic join where the server offers no node.
