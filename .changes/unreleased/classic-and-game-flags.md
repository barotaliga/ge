---
type: Changed
title: -game names a mod's folder
---

A mod's folder is `-game <folder>`, as each classic game names one, on `se`, `sesv` and `setv`; it replaces the window's `-mod`, and on `sesv` it is the same as `--mod=<folder>`. `secli` takes `--game=<folder>`. The numbers `-game 1` and `-game 2` are gone.
