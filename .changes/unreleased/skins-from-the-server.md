type: Added
title: Skins and player figures fetched from the server
---

Shooter's Edge's first game, joining a server, now downloads the skins and player figures (`players/<model>/`) the players wear that you lack, keeps them in your game folder for next time, and draws them once they land; `noskins 1` fetches nothing. A server offers the files in its game folder when downloads are on, and the console's `serverskins` lists the skins and figures it offers.
