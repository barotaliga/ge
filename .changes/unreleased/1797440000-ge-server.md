---
type: Added
title: ge server runs a game's dedicated server headless
---

`ge server [--game=<binary>] --map --bots --for` builds a game's dedicated server, either the one its `ge_add_server` names or the binary given with `--game`, and runs it headless with its bots. It answers with the run's digest and its input log. `--replay=<log>` runs a log again and checks it against the recorded digest, `--port` runs the server for players instead of offline, and `ge server cfg [<prefix>]` prints each server setting with the file and line that set it.
