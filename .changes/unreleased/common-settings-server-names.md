---
type: Changed
title: One port and one cheats switch under every game's name
---

A server's port answers to `net_port` and `sv_port` alike, on a dedicated server and in a hosting window, so one config line serves both. Quake II's `cheats` is now the server's `sv_cheats`, still taking hold on the next map as the game has it, and the server's status line reports the value set. QuakeWorld's `s_restart` works as `snd_restart`.
