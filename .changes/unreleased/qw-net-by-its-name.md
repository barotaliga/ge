title: QuakeWorld's network code is called qw
---

Shooter's Edge's QuakeWorld protocol code (its server, client, TV, forward, relays and tools) is named `qw_*` in files and code instead of `classic_*`, and its comments say QuakeWorld. The single-player netgame protocol's two files are `q1_*`. Nothing a player plays, and no file a player keeps, changes.
