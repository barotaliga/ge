type: Added
title: Quake II's recorded fast runs read as routes
---

The `se-q2-speedruns` lab reads a folder of the player's Quake II recordings into each run's route (every 0.2 s), the items picked up, where a secret or a goal counted, the boosts and the time, drawn on the live map. A recording that stuffs a command before its server data now plays.
