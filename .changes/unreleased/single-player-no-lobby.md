---
type: Fixed
title: A single-player game in the window starts on its map, not in the deathmatch lobby
---

With `sv_lobby 1` (the window's default), NEW GAME and `sv deathmatch 0` followed by `map` opened the deathmatch lobby's warmup, so Quake II's maps started with no monsters. The lobby is now only a deathmatch game's.
