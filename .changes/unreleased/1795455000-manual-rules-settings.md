title: The rules' own settings in the reference manual
---

`ManualInfo::more` adds settings that live outside a console to a manual pass, and `describe_settings` describes a `Cvars` alone. Shooter's Edge's window and dedicated server now list each game's rules' own settings (`deathmatch`, `coop`, `skill`, `fraglimit` and the rest) in the reference manual.
