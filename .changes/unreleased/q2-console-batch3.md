type: Added
title: Quake II's player page picks the figure and skin; ESCAPE puts the help computer away
---

Quake II's player setup page lists every figure in the game's files and its skins and writes the `skin` setting; ESCAPE with the help computer, a scoreboard or the inventory up puts it away before it opens the menu; `skins` reads every player's figure again on a Quake II server; and the console gains `$cl_fps`, `$cl_numentities` and `$cl_weaponmodel`.
