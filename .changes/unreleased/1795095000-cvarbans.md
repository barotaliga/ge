---
type: Added
title: Quake II servers can turn away players by their settings or user info (cvarban_add, userinfoban_add)
---

`cvarban_add <setting> <match> [log|print|stuff|kick] [text]` makes a Quake II server ask each player's game for a console setting's value at every map and act when it matches. For example, `cvarban_add gl_modulate >3 kick "Too bright."` kicks a player whose gl_modulate is above 3. `userinfoban_add` does the same with user info keys (a skin, a name). An entry that kicks turns the player away at connect. A match can be a number compared with `=`, `<` or `>`, text that `~` contains, `*` for any value, and `!` turns any of them round. `cvarban_check` asks every player again. The Quake II spellings (`addcvarban`, `adduserinfoban` and the rest) work too.
