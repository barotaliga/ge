type: Added
title: The network's tools (ge net inspect, stats and sim)
---

`ge net inspect <pcap>` decodes a capture datagram by datagram in the engine's own wire format. `ge net stats <pcap>` measures each connection as the capturing node saw it: packets and kbit/s each way, round trip, loss each way, duplicates, reorders and resends. It also charts the node's bandwidth, round trip and loss over time. `ge net sim` runs fake-traffic clients and a host over chosen link conditions with no game (presets, a traffic mix, `--link` overrides), prints the numbers the `net-link` lab does, and writes the host's capture. `ge::net` gains `analyze_capture`, named traffic mixes (racing, action, rpg, world, lockstep, also on the lab's `--mix`), and a live node's capture with a size limit that `save_capture` writes to a file. Game repos get a `multiplayer` skill.
