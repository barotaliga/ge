title: A game's own rules save and autosave through the rules runner's table
---

Shooter's Edge's window now asks the running rules, through their table of calls, whether a game can be saved, for the save itself and for the autosave made at a level's start, instead of asking for the sequel's server by name. A later game's rules save the same way. Saving and loading play as before.
