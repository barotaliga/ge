type: Added
title: The frame core
---

`engine/render` (built with the GPU as `ge_render`) draws a frame: a `FrameView` and its reversed-z camera, a pass table checked for order, per-pass GPU timings and stats, a physically based sky from lookup tables built by compute with aerial perspective behind one haze function, a GPU-culled geometry clipmap for any heightfield, and a post pass (exposure from the sky, tone curve, dither, encoding). Fall Line's window now shows its generated mountain, and the `world` lab photographs it from named views headless. Not part of the published package yet.
