---
type: Changed
title: Bots react to each sighting in a drawn time
---

A Shooter's Edge bot now takes a reaction time drawn for every enemy it sights, skewed to the slow side the way people's are: an expert about 160 ms, an average player about 230 and a novice about 300. It neither turns onto him nor fires until that time is up. Only an enemy the view was already on, pre-aimed at a doorway, is taken in under 100 ms. A bot also goes after an enemy it only heard 100 to 200 ms later than one it saw. The hands track faster once on him, so matches have more frags.
