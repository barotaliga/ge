---
type: Changed
title: the proxy link is coded and its frames are shorter
---

The link between a near and a far proxy now range codes each game datagram against the last one the other end holds, with models both ends learn as they go, and each link frame's header is ten bytes instead of eighteen. A classic client's traffic through the pair costs about two thirds of the game's own bytes, where it cost about the same as the game's before; three copies on a lossy link cost about two. The hops' `proxy` turns it on; it needs both proxies from this release.
