title: A Quake II pack's NEW GAME plays its intro and starts on its own first map
---

NEW GAME under The Reckoning or Ground Zero started the base game's first map. It now takes the level each game's `default.cfg` names for `newgame`, so The Reckoning plays its logo and intro movies before `xswamp`, Ground Zero its intro before `rmine1`, and the base game its intro before `base1`.
