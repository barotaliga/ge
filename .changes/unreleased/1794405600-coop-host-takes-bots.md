MULTIPLAYER > NEW GAME with GAME TYPE COOPERATIVE now starts a real co-op game, so `addbot` seats companions beside you; it used to start the campaign with co-op off and refuse every bot. `coopgame`, `newgame` and `sv_coop 1` typed during a running game now start a new game with their settings instead of only changing the map.
