type: Added
title: The engine's server core
---

`engine/server` (`ge::server`): one game's server as a `ServerGame` table of functions, run dedicated by `server_main` (a game's binary made with `ge_add_server`) or stepped as a listen server, with the node, session and LAN hosting round it; settings from `server.cfg`, then flags (`--name`, `--description`, `--ip`, `--port`, `--maxclients`, `--map`, `--bots`, `--password`, `--visibility`), then `+commands`. `shooters_edge_server` now runs on it.
