type: Added
title: The net graph in the corner (r_netgraph)
---

`r_netgraph 1` shows how the packets from the server arrive in a game joined on a server. Each packet gets one bar showing its round trip; red bars mark packets that never came. The ping and the loss are shown above the bars. It sits under the speed and the clock in the top-right corner. It is the engine's, so any game's client can record its packets and draw it.
