title: The hub: a game's live servers as a JSON API
---

`engine/hub` is a community's hub for any game. It reads the masters' lists and every listed server's status record, ranks matches by interest (full human matches first, bots and stale score screens last), and answers `/v1/servers`, `/v1/servers/{address}`, `/v1/streams`, `/v1/nodes` and `/v1/masters` as JSON over HTTP/1.1, with server-sent events for one server's changes. A game's hub binary is three lines over `ge_add_hub` and its `HubSpec`; `--serve-master` runs the master in the same process. Shooter's Edge ships `shooters_edge_hub`.
