---
type: Added
title: A server runs a line of your choice after each map loads (sv_mapcmd)
---

`sv_mapcmd "<line>"` makes a dedicated server run that console line once after every map loads, the first one too: `exec` a config for each map, `say` a greeting, set something every map. Every game's server has it; Quake II's `sv_changemapcmd` is the same setting.
