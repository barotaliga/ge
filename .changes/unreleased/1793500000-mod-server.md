title: The mod server
---

Shooter's Edge runs a multiplayer mod's compiled QC. Every standard builtin by number and the common extensions are installed; `checkextension` answers for them. The server calls the mod's hooks around the loop and mirrors the extension fields, and the map's entity text spawns into the mod's own fields. A progs is loaded from a path (`--progs` or the `sv_progs` cvar) with its `.lines` table. An assembled deathmatch test mod plays a match against bots that replays to the bit, and the new `se-mod` lab tabulates and draws it.
