type: Added
title: server.cfg in layers, with where every value came from
---

A dedicated server reads its settings in layers (`engine/server/config.hpp`): the base game directory's `server.cfg`, then each mod's lowest first (`--mod=a,b`), so a mod's file changes only what it sets; then a profile (`--cfg=duel`, from the highest directory that has one), the command line and the server's console. Every server value keeps the file and line that set it, and `<game>_server --explain[=prefix]` prints each value with its source and what it overrode. The server gains `sv_motd`, `sv_admin`, `sv_maprotation`, `sv_maxspectators`, `sv_spectatorpassword`, `sv_rendezvous` and `sv_mod`, and the flags `--root --base --mod --cfg --motd --admin`. The console's registry can be watched for every set it allows (`Cvars::set_watch`). The `server-cfg` lab draws every value across the layers.
