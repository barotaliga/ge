type: Fixed
title: A Quake II server prints who joins, leaves and is refused, and sv_logfile keeps it
---

A dedicated Quake II server printed nothing about its players: joins, drops, refusals, bans and its rules' own messages now show on its terminal, and `sv_logfile <file>` adds them to that file in the game's folder, each line stamped with the server's time.
