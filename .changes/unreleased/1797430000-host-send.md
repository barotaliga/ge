---
type: Added
title: A game's player CLI sends console lines to the server it hosts
---

`<game>_cli host --dedicated` now starts the server through the engine's launcher (`engine/server/spawn.hpp`), which can hand it a cfg file with `--cfg=<file>`. The new `host send <port> <line>` sends a console line to a dedicated server the CLI started: `host send 27500 mod arena` switches its mods and restarts its match. `host stop` now also removes the handed cfg and the console file along with the record.
