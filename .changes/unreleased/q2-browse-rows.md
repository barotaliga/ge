title: Quake II's multiplayer page browses q2servers.com and the address book
---

MULTIPLAYER and the in-game page in Quake II now have "browse q2servers.com", which lists that site's servers, and "browse address book", which lists the address book, a servers.lst in the game's files and the LAN. pushmenu servers takes the same sources from the console.
