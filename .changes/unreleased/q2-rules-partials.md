---
type: Changed
title: Quake II's cheats wait for the next map; the shutdown line; viewthing
---

In Quake II, a change to `cheats` now takes hold on the next map as in the original game, and so does every other setting of the rules that waits for a new map. The server console says `==== ShutdownGame ====` when the server quits or restarts, and a delayed trigger with nobody to hand on says `Think_Delay with no activator`. A map's `viewthing` shows its model, animating.
