type: Fixed
title: The console lifts at Quake's own speed after Quake II was played
---
One config serves every game, and Quake II's console speed (3 screens a second) was read at a
Quake start as 3 lines a second, so the console took over a minute to lift off the start screen.
A value that is another game's default is now taken as that game's, and the loaded game's own
default is used.
