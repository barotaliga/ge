title: A picked game starts with its console down, then slides it up
---

Shooter's Edge's main menu has no HELP row, the recordings behind it show no play bar, and a game picked on SELECT GAME closes the menu, holds the console over the screen with its packs listed and slides it up at `scr_conspeed` (the game's own unit) once its first recording plays. The engine's console gains `set_full`, the whole screen held while a game loads.
