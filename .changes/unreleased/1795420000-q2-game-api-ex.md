type: Added
title: A hosted Quake II game library gets the extended interface; the relay tells renames and leaving
---

A Quake II game library hosted unchanged may now use the extended interface: a sound to one client, a configstring read, a trace against one entity, the visibility test of a chosen kind, a tagged block grown, and files read and written beside the game. The server takes its answers on saving, its own end of frame and what each client sees of each entity, and the `sv_features`/`g_features` pair carries proper in-use, every disconnect, the extra user info and IPv6 addresses. A relay tells a channel a viewer's new name and leaving and can hide the version trigger in chat (`mvd_filter_version`); the dedicated terminal prints `console_prefix` before each line.
