type: Added
title: The QC VM
---

`plugins/progs` runs compiled QC bytecode deterministically: a loader that checks every record, all 66 opcodes on 32-bit floats, entity and global memory, strings, a builtin table the game fills, an extension registry, runaway and depth guards, faults with a QC stack trace and a per-function profile; an assembler builds bytecode for tests, `ge qc disasm/run/trace/profile` inspect a progs headless, the new `qc` lab profiles and times it, and Shooter's Edge's loop can now be driven by a loaded progs.
