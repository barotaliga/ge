---
type: Added
title: Quake II servers mend four stock maps' visibility and can replace a map's entities from a file
---

Players at a few spots on q2dm1, q2dm3, q2dm8 and one of the second mission pack's maps are no longer hidden from players close by: the server adds what those spots should see as the map loads (`sv_vispatch 0` plays the maps as they were made). `sv_entpath <folder>` plays a map with the entities of a file in that folder, `<map>@<crc>.ent` for one build of the map or `<map>.ent` for any. Quake II's spellings (`map_visibility_patch`, `map_override_path`) work too.
