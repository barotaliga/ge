title: Map design: the map from above and its likely rocket jumps
---

The `map-design` skill guides an agent through designing a multiplayer map for the classic brush maps: the game's measured movement (the `map-moves` lab), layouts by mode, a plan's `modes`, `area` and `trick` statements (or an intent-only `.intent` file for any map), and bots' matches held to that intent (the `map-intent` lab). The `map-overview` lab draws any version 29 map from above in its own textures and light, with the intent's areas, the tricks, every item as the game's own model, and one likely rocket jump a ledge found by `plugins/shooterbots/jump_finder.hpp`, which calculates each jump's arc through the map (ramps and rising lifts included) and drops the ones a walk matches.
