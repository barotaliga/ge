Shooter's Edge reads and writes the classic text save: `save <name>.sav` writes one into the game folder, and `load <name>` loads ours or, failing that, `<name>.sav`, so a single-player game saved by another engine plays on here. A save from an engine that numbers the map's entities right after one player is moved onto this server's numbering. The menu's SINGLE PLAYER ▸ LOAD and SAVE pages are twelve slots, each showing its save's line.
