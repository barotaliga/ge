type: Added
title: ge lab sweep runs a lab with one constant at several values
---

`ge lab sweep <id> --set=<name>=<a>,<b>,... -- <lab flags>` runs a lab at each value of one constant in your code and prints every metric side by side, with the current value starred:

- **The constant:** any `constexpr` defined on one line, such as a spec's or a tuning table's. Name it bare (`kGrip`) or qualified (`spec::kGrip`). `--in=<file>` picks the file when the name is defined in several.
- **Each run:** the initializer is rewritten in place, only the `labs` target is rebuilt, and the lab runs with `--tag=sweep-<name>-<value>`. Each run's pictures stay for `ge lab diff`. `--metrics=<word,...>` narrows the table.
- **Afterwards:** the file is put back and the labs are rebuilt on its own value. A sweep killed half way keeps a backup under `build/<preset>/ge-sweep/`, and the next sweep restores it first.
