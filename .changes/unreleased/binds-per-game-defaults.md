---
type: Fixed
title: Each classic game keeps its own default keys
---

The shared config now saves only the keys you rebind. Quake and Quake II each keep their own default layout under your changes, so playing Quake II no longer leaves Quake's weapon keys, jump and scoreboard on Quake II's commands. A config saved by an earlier version still holds every key; RESET TO DEFAULTS in OPTIONS (or `bind_defaults`) puts the game's own layout back.
