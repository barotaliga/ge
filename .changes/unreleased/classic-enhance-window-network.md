---
type: Changed
title: Enhancing from the menu uses the trained upscaler once its weights are on the computer
---

When the classic enhance tool has already fetched the trained upscaler's weights, enhancing a game
from OPTIONS ▸ CLASSIC ENHANCED upscales the textures with them, as the tool does, while TRAINED
UPSCALER is on. Without the weights it uses the faster edge-aware upscaler and downloads nothing.
