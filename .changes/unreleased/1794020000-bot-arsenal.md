type: Changed
title: Bots read a game's weapons from its arsenal
---

Shooter's Edge's bots choose, aim, fire, stock up and plan round weapons from one table a game supplies, so the same bot fights with the first game's eight weapons or the sequel's ten and its six ammunitions. The sequel's server now sends a player's held and carried weapons and every ammunition. The first game's bots play exactly as before.
