---
type: Changed
title: Quake II's fixedtime is the same setting as host_framerate
---

`fixedtime` in a Quake II game is now the same setting as every game's `host_framerate`, written in milliseconds: `fixedtime 50` sets `host_framerate 0.05` and says so. It is still a cheat under its Quake II name and goes back to 0 when cheats are turned off. `host_framerate` now accepts up to one second a frame.
