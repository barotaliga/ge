More of the classic server's settings, each under our name with the classic name still working: `sv_spectalk` 0 keeps a spectator's `say` to the other spectators (shown as `[SPEC] <name>:`, as a spectator's `say_team` always is) when the mod leaves chat to the server; `sv_safestrafe` holds a player's reversed sideways move apart by that many commands and tells clients in the server info; `sv_antilagexact` (`sv_antilag_no_pred`) rewinds to exactly the frame the shooter saw; `sv_voipecho` (`sv_voip_echo`) sends a speaker his own voice back to test it.
