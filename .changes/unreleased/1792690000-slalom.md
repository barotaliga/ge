title: A slalom set over a built map (R31), its analysis and the slalom lab
---

`mapgen::set_slalom(level, run)` sets a slalom over a built map (a single piste or a ski area's course): the steepest stretch of the piste that drops a slalom's vertical, prepared for the race (`course_prep`: the piste's kickers levelled, a start drop cut out of the hut's door, the course groomed hard and combed smooth, the woods cut for it and its finish arena), and its pole gates set like a course setter sets them (open gates in a rhythm, hairpins, verticals and delays down the middle, the last gate fast), with the racing line round them. The second run is set afresh on the same stretch. The map names the course in `Level::race` and keeps the map it was set over. `analysis::analyze_race` holds a course to R31, and `analyze_level` answers it on a map with a course. The `slalom` lab draws both runs straightened and the map from above, with the gate table.
