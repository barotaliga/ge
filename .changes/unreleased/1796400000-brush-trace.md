---
type: Added
title: The brush trace for version 38 maps
---

`plugins/brush` now reads a version 38 map's brushes, their sides' planes and surfaces, and each leaf's brushes. `BrushTracer` (`brush/trace.hpp`) sweeps a box through them, and answers the contents at a point, with every float step's precision fixed and held golden. `write_brush_world` writes hand-built brushes as a version 38 map for tests. This is the collision the sequel's move will run on.
