---
type: Changed
title: Shooter's Edge starts in the classic game loaded last
---

Shooter's Edge keeps which classic game was loaded last and where it is installed, however it was picked (OPTIONS ▸ CLASSIC ENHANCED ▸ LOAD GAME, `basedir` in the console, or `-basedir` at the start), and every later start opens it, with its own menus, font, HUD and maps, until another game is loaded. `-basedir` still names another for one start.
