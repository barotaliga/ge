---
type: Changed
title: Shooter's Edge starts in the game played last
---

Shooter's Edge keeps which game was played last (`fs_basegame`) and where each classic game is installed (`fs_basedir_q1`, `fs_basedir_q2`), however it was picked (SELECT GAME, OPTIONS ▸ CLASSIC ENHANCED ▸ LOAD GAME, or the console), and every later start opens it, with its own menus, font, HUD and maps, until another game is loaded.
