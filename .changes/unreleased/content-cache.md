type: Added
title: Fast loads from a content cache
---

`save::ContentCache` keeps what a setup builds slowly (a generated map) on a disk under a key that names the setup and the stamp of the code that builds it, so a second load reads it instead of building it again; a damaged, stale or foreign entry is refused and rebuilt. `ge_source_stamp` (CMake) makes that stamp from a set of source directories. A generated mountain map's every type is described for the save file, and Fall Line's race and free-ride maps open through the cache (the window keeps one in the player's folder). The `save-run` lab times a first load against a cached one.
