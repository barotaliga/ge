type: Added
title: Maps built from a plan or a drawing
---

`plugins/brush/compile` compiles a level written as a text plan (rooms carved from solid, solids, walls, stairs, ramps, liquids, entities, symmetry) or drawn as an SVG floor plan into a sealed, lit version 29 map with its clip hulls; a leak is refused with the way from an entity to the gap. A game's player CLI builds one with `map build <plan|svg>` (`--textures=<folder>` takes the pictures from the player's own packs) and shows a drawing's plan with `map plan <svg>`; Shooter's Edge's `secli` has both. A plugin's command now declares its own flags (`gamecli::Spec::command_flags`). The `map-build` lab pictures a compile. Shooter's Edge gains The Keeps, a four-against-four map built this way.
