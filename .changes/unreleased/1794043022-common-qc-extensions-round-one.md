type: Added
title: More of the common QC extensions for mods
---

Shooter's Edge's server now offers `etos`, `findfloat`, `vectorvectors`, `asin`, `acos`, `atan`, `atan2`, `tan`, `strtolower`, `strtoupper`, `strreplace` and `strireplace`, each under its usual extension name, so a mod that asks `checkextension` for them gets them.
