---
type: Changed
title: ge lab publish fits its page; ge digest builds only the labs
---

`ge lab publish` builds a page past the published-page limit again with smaller pictures (three quarters as wide a round, down to 180 px) and says what width it took, so a run with many or large shots publishes in one call. `ge digest` builds only the labs executable instead of the whole tree, so checking digests no longer fills a small disk with test binaries.
