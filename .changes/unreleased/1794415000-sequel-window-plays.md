Shooter's Edge tells which classic game an install is by its folders (at the start, from the game kept, and from LOAD GAME, which swaps the game's adapter in place). A map of the 38 family is read for the server with its brushes and plays on the sequel's rules, whatever the program, so its player spawns, lands and walks. A turn the spawn gives is taken once by a client that takes the server's view. Bots sit such maps out for now. Lab `se-sequel` walks each map that has brushes on the window's own server and draws the view where the player stopped.
