type: Added
title: A recorded match closes with its report, and the hub links the match to its demo
---

A match recorded on the server now ends its replay file with the same match report the server
sends to the account master, together with the final scores. When the hub takes that demo into its
archive, it finds the match it already holds and links the match's page to the demo, so a match's
stats and its recording are one thing.
