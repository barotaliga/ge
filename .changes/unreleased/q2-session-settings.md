type: Added
title: Quake II's map commands, game clock, console log and effect switches
---

Shooter's Edge's Quake II gains `cl_beginmapcmd`, `cl_changemapcmd` and `cl_disconnectcmd` (a
player's commands run as each map begins, changes and the game is left), `timescale` and
`fixedtime` (cheats on a hosted game), `cl_autopause`, the read-only `cl_running`, `cl_paused`,
`sv_running` and `sv_paused`, the console log (`logfile`, `logfile_flush`, `logfile_name`,
`logfile_prefix`), `cl_gibs`, `cl_noglow`, and its spellings `cl_entities`, `cl_particles`,
`cl_lights` and `cl_blend` of our switches. Every game gains `con_history` and `s_swapstereo`
(the synth's new `swap_stereo`).
