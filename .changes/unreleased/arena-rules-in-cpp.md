type: Changed
title: the deathmatch's rules are C++
---

Shooter's Edge's own deathmatch (the baseline arena: weapons, items, armour, deaths, frags, doors, plats, triggers, deathmatch 4, a loaded game's words) is now C++ (`games/shooters_edge/rules/`), run by the mod server as a native program where the compiled QC ran. It plays the QC's matches to the bit; the arena's QC sources are deleted (the campaign's stay until they are carried over too).
