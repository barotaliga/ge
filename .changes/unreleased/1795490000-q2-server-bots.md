---
type: Added
title: Bots on a Quake II server
---

A Quake II dedicated server now fills `sv_bots` slots with bots in deathmatch, as a QuakeWorld server does: they fight from the first map, stay through every level change, count toward a full server, and show as bots in the server's status and in the match's end stats. Quake II and QuakeWorld now seat their bots through the same code.
