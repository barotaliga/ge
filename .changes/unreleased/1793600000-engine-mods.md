type: Added
title: Engine mods in C++
---

A game on the engine can load mods written in C++: `engine/mod` (published as `ge::mod`) holds the C ABI (`mod/abi.hpp`, a versioned table each way that grows at its end), the package's manifest with each library's SHA-256, and a loader that refuses a wrong ABI, game or file with a message naming the version and the next step. `cmake/Mods.cmake`'s `ge_add_mod` builds a mod as a package, and `ge mod new`, `build`, `check` and `pack` take one from a template to a package. Shooter's Edge offers its program seam to mods, with the mod's state and random stream in the match's snapshots, so a modded match replays to the bit; the sample mod `rocket-bounce` and the new `mod` lab show it. The engine's float flags moved to `cmake/Fp.cmake`, which a mod's build includes too.
