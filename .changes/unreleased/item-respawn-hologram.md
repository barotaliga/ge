type: Added
title: Items come back as a blue hologram
---

With classic enhance's ITEM RESPAWNS (`ce_respawns`, on by default in the modern look), an item that was taken shows where it will lie as a blue see-through hologram for the last half second before it comes back, filling in until it is solid, instead of popping into being. It works in both classic games, on a game you host or play alone and when you join a server of ours, which now tells the game when each taken item comes back (other clients are never sent it).
