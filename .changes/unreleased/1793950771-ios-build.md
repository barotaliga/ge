type: Added
title: The engine builds for iOS and iPadOS
---

The presets `ios-sim` and `ios` cross-build the engine and a game's app for the iOS Simulator and for iPhone and iPad, against Dawn's prebuilt mobile archives from the pinned release (`cmake/Dawn.cmake` also knows Android's). A mobile target builds one game (`GE_MOBILE_GAME`) without the host tools (`GE_HOST_TOOLS`); the codecs are built for the target. `ge::platform::run_app` is a windowed game's entry (SDL's UIKit start on iOS), and `ge_app_bundle` (`cmake/App.cmake`) makes its app bundle, its identifier `dev.local.<game>` unless `GE_BUNDLE_ID_PREFIX` is set in the environment.
