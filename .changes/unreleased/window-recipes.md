A recipe is a cfg run with `+exec` that plays the window as a person would: `sleep <seconds>` waits in wall time, and Shooter's Edge's menu takes `menu_press <key>...`, `menu_select <item>` and `menu_list` (the page up as text), so a script can join a server, open SERVER SETTINGS, change a row, read the page back and take its screenshot. SERVER SETTINGS now fills from a stock QuakeWorld match mod's listings (they were asked with a word the server refused).
