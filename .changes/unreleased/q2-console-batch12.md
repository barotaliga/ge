The window's console now takes `sky <name> [rotate] [axis x y z]`, which draws that sky box through the map's sky until the next map, and `timerefresh`, which times 128 frames turning a whole circle. Quake II's `seek` says when no demo is playing, the single-player loading plaque gives up after two minutes, and START SERVER shows the server's host name.
