---
type: Fixed
title: The lobby's keys and words reach a server joined
---

On a server joined over the network, F1 (ready or break), F2 (the other team), F4 and the console's `ready`, `break`, `team` and `start` went to the window's own lobby, which had none, so a player could never ready up for the match. They now go to the server joined, so warmup, the countdown and the match run as on the window's own server.
