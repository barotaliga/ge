---
type: Added
title: A dedicated server for Quake II that its own clients join
---

`sesv -classic q2` runs Quake II's rules as a dedicated server on Quake II's own protocol, so an unmodified client of Quake II joins it and plays, directly or through our proxy. A map with no sky gets the default one, and a client's download is refused so that it plays on with the files it has.
