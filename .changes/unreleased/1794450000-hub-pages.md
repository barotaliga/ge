The hub now serves its own website beside the JSON API: the Servers page (a card for each live server in order of interest, with its scoreboard and Join, Spectate and Watch links, and mode filters), the Players page, and a scoreboard overlay for one server. Plain HTML with one stylesheet in a dark and a light scheme, no script, refreshed every 5 seconds.
