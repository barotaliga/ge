No cloud ends in a hard cut any more. A cloud crossing the sun or the moon used to end in a sharp line against the disc's glow. The cloud pass now marches on round the light, fades out the layers behind a nearly opaque one instead of dropping them, and skips no thin layer, so every edge there is continuous. A dense cloud's edge is also feathered by its depth, so it thins out gradually instead of ending all at once.
