type: Added
title: The easy jump (cl_speedjump)
---

Shooter's Edge players who cannot strafe can still bunny hop for speed: with `cl_speedjump 1`, holding forward and jump hops on every landing and gains about half of what the best strafe would gain, the way turning with the view. A strafe still gains more. Servers decide with `pm_speedjump` (0..1, the share): the window's own listen server allows it at 0.5, a dedicated server only when its owner sets it, and a server that does not know it ignores the ask, so the classic move is unchanged everywhere it is off.
