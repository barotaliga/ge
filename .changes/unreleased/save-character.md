type: Added
title: A character carried from one run into another
---

`save::extract` cuts a game's character (the chunks `GameSpec::character` names) out of a run's save as a file of its own kind, and `Run::save_part`, `Run::import`, `play::save_character` and `play::import_character` write one from a run and carry it into a run opened on another setup, replacing that run's character and nothing else. `ge save part`. Fall Line carries the skier's profile: his injuries and his career over every run. The `save-character` lab.
