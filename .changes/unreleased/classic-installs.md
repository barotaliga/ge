type: Added
title: classic installs found and played as their bundles lay them out
---

Shooter's Edge plays a classic install it is started inside (ahead of the game loaded last), and placed in the folder above several it finds each one by its folder's name or by what it holds, telling shareware, registered, demo and full games apart by their packs (`games` lists them, `games <n>` loads one). An install's configs run in its bundled client's order, with that client's folder on the search path, and settings the game lacks are passed over quietly. A map's place names can be made in the game: `addloc`, `removeloc`, `clearlocs`, `saveloc`, `loadloc` and `loc`.
