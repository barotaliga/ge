title: A game adapter for each classic game
---

Shooter's Edge asks a classic game's mods, programs, maps, map textures and demos through one adapter per game (the first game's built from the code that did it before, its pictures unchanged), each program file carries its form and side so a form with no runner is named rather than misread, and the window gains the console commands `mods`, `maps` and `demos`.
