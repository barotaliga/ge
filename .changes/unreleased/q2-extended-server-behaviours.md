type: Added
title: Quake II servers behave as an extended game expects
---

On a server hosting a game with the protocol extensions, traces read every clip brush in a solid leaf and stop a box that stays inside a brush, players and projectiles the game flags pass through masks that do not ask for them, looping sounds are heard by distance rather than by sight, entities marked always-sent reach every client, and a player's no-flares and no-footsteps settings drop flares and the newer step and ladder sounds.
