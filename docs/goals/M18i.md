Status: in progress

M18i is the picture: the world pass, the models, sprites, particles, dynamic lights, the screen
blends and the two looks. It is built in parts, and each part builds only on what is on main.

| Part | What | State |
| --- | --- | --- |
| M18i1 | Morph meshes (`engine/render/morph.hpp`): vertex-animated models with frames blended on the GPU, team colours from tint ramps, glowing texels, sharp or smooth skins, a game's own light; the `gpu-morph` lab | done |
| M18i2 | Sprites: camera-facing quads by orientation type, frames, additive and alpha | open |
| M18i3 | The classic model reader feeding morph meshes, with the palette's colour rows as the tint ramps | waits for the model reader's plugin on main |
| M18i4 | Morph meshes lit by the lighting pass's local lights | waits for the lighting pass on main |
| M18i5 | The world pass, particles, dynamic lights, screen blends and both looks in `se-world` | open |
