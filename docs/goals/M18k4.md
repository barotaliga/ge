**Round 21, the network settings** (round 12's list):
- `showpackets` (1 both ways, 2 sent, 3 received) and `showdrop` (the classic channel's
  `ChannelTrace`, `classic/protocol/channel.hpp`): each packet to and from the server joined a
  console line `<ms> --> s=<seq>(<reliable>) a=<ack>(<its bit>) <bytes>`, each loss
  `<server>:Dropped <n> packets at <seq>` and each stale one `<server>:Out of order packet <n> at
  <newest>`; both games.
- `rcon_address`: `rcon` with no server joined goes there (the game's server port when none is
  given) over a socket of its own, and the answers are said until it has been quiet for 5 s;
  joined, rcon goes to that server in both games (Quake II's went nowhere before).
- `cl_solid_players` (1): the other players block your predicted moves on a QuakeWorld server.
- Not taken: `cl_earlypackets` is how our client always reads (every frame, not only on move
  ticks), so a setting would change nothing; `cl_nolerp_on_entity` waits for the client's view
  to know the mover underfoot; `qport` is chosen per name.
Held by `tests/classic_protocol_channel_test.cpp` and `tests/shooters_edge_remote_test.cpp`; the
facts are in `porting/shooters-edge/client-teamplay-sets.md` § F.

**Round 24, chat on the console** (ranked candidate 6, the Quake half):
- `cl_chatmode` (the classic layer's name for the engine's `con_chat`, which gains 2: a line
  whose first word names a command, alias or setting, in any case, runs, any other is said). Our
  default stays 0 (every line a command, an unknown word sent to the server), since a mod's own
  words (`ready`, `break`) are no setting of ours and 2 would say them. In every mode a line
  starting with `\` runs like one starting with `/`, and one starting with `//` is a note, shown
  and never run (`engine/console/view.hpp`).
- Chat sounds (`client/chat_lines.hpp`): `s_chat_custom` (0 none, 1 every chat line, the default,
  2 team lines only; `cl_chatsound` its old name), each kind's file and volume (`s_mm1_*` to
  everyone, `s_mm2_*` team, `s_spec_*` a spectator's, `s_otherchat_*` the rest; the
  `con_sound_*` spellings), `misc/talk.wav` each, heard everywhere. A player hears the game's own
  file for a speaker known (only the volume is his); watching, every file is his. Our client played
  no chat sound before.
- `msg_filter` (1 lines to everyone and spectators', 2 team lines), `con_timestamps` (1 ` 9:05 `,
  2 the seconds too while watching or in standby), `con_highlight` and `con_highlight_mark` (a
  line naming you, not at its start, marked; our console draws every line in one colour, so 1's
  plain line looks as before), in the classic layer, on both games' servers joined.
- Not yet: `con_notify`, `con_mm2_only`, `con_clearnotify` and the HUD's notify element; the
  sound triggers in team lines (`tp_soundtrigger`); Quake II's `cl_chat_notify`, `cl_chat_sound`,
  `cl_chat_filter` and `scr_chathud*` (its client's source was out of reach this round).
