**Team chat's pointing (done):** what the player points at (`client/team_point.hpp`: the thing
nearest the view's line in sight, from the pointing set, named in the team's words) fills `%t`,
`%x`, `%y` and `%j` (`tp_pointtimeout`), says `tp_msgpoint`, and steers `tp_msgenemypwr`, `safe`,
`killme`, `utake`, `quaddead`, `getquad` and `getpent` (a glowing enemy, a teammate). On a server
joined or a demo it reads the protocol's entities and players, in the window's own game the
server's. Held by `tests/shooters_edge_team_point_test.cpp`; pictured by `se-client --point=1` on
a real map (the quad, the heavy armour and the beam gun pointed at). The server's stop-sound
message needs nothing: the reference server never sends it, and every client path reads it.
