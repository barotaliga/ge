Status: open
Milestone: **Launching servers** (`engine/server/spawn`, `ge server`): the game's HOST page spawns its dedicated binary as its own process on macOS, Linux and Windows, hands it a cfg, joins it, finds it again by its local address after a restart and stops it; the dedicated server launches matches (the rotation, a mode, a mod switch that remounts the search path and re-reads the config layers); `ge server --game=<g> --map --bots --for` for any game with a server
Exit: A client spawns a dedicated server, joins it, quits, a second client finds it and stops it; a mod switch re-reads the layers and the next match runs under them
Labs: `server-launch`

Desktop only: the stores forbid spawning processes, so there a game hosts a listen server.
