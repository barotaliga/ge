Signing and distribution: a package signed (Ed25519 over the manifest, which carries every
file's hash) and the game's list of trusted keys; a server's mod list sent to a joining client
with each package's hash, fetched from where the server says and checked before it loads;
`ge mod sign` and `ge mod publish`. Design: [`docs/mods.md`](../mods.md) § The package.
