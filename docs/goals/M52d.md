Signing and distribution: a package signed (Ed25519 over the manifest, which carries every
file's hash) and the game's list of trusted keys; a server's mod list sent to a joining client
with each package's hash, fetched from where the server says and checked before it loads;
`ge mod sign` and `ge mod publish`. Design: [`docs/mods.md`](../mods.md) § The package.

## Progress

- Signing: done. `engine/mod/signature.hpp`: `mod.sig` beside the manifest, the signature over
  the manifest's bytes in the engine's one scheme (`net/crypto.hpp`); the trusted keys (`<key>
  <name>` a line); the loader's verdict (not signed, unknown key, trusted and named, broken and
  refused) and `trusted_only`; `ge mod key`, `ge mod sign`, `ge mod check --trusted`. Held by
  `tests/mod_signature_test.cpp`: a manifest changed after signing is refused naming the manifest,
  a library changed after signing is refused naming the library and its hash. Docs:
  [`docs/mods.md`](../mods.md) § Signing.
- Distribution: done as a list, never a download (Niclas, 2026-11-14: "the clients don't need
  them"; only the server runs a mod). The server's `*mods` (serverinfo and public status) names
  each package and its version; the browser shows it, the hub's API carries it. Held by
  `tests/shooters_edge_rules_mod_test.cpp` and `tests/shooters_edge_classic_browse_test.cpp`. A client
  joins a modded server as any other, since it runs no rules of its own. `ge mod publish` is left
  out with the download. Docs: [`docs/mods.md`](../mods.md) § Distribution.
