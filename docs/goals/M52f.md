A C++ mod package on the real server, not only in the scripted match (design: `docs/mods.md`
§ On the server).

**Built:**

- `RulesMods` in the runners' common part (`games/shooters_edge/server/rules_runner.hpp`): the
  host's loaded tables; `RulesRunner::start` lays each mod's seam over the loop's program after the
  runner's own start and runs its `match_start`; `frame` puts the mods' log lines on the console;
  `rules_hash` folds each mod's run into the loop's digest. `RunnerCalls::program_seam` marks the
  runners that take mods (the bytecode program's and the compiled module's); the sequel's refuses
  one until M52g.
- The playable server (`games/shooters_edge/net/classic_game.cpp`): a folder in `sv_mod` holding
  a `mod.manifest` is loaded as a package (under `--root` or as given) and stacked on every map's
  rules; its digest is `rules_hash`. A refused package, or one named for a coop campaign, stops
  the server with the reason.
- The mod seam passes a hook its own `self` as the loop set it (a bytecode function may leave
  its `self` global elsewhere).

**Held by:** `tests/shooters_edge_rules_mod_test.cpp`.
