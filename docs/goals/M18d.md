The QC compiler and the baseline deathmatch mod, built in a clean room from the language's
written specification (`porting/shooters-edge/qc-language.md`) and the bytecode note
(`progs.md`): no existing compiler or mod was read.

- **The compiler** (`plugins/progs/qc_compile.hpp`, `compile_qc` and `compile_project`): one
  pass over the sources in the project file's order; the classic and the C declaration forms,
  builtins by number, frame functions and frame macros, `for`, `break` and `continue`; each
  function's parameters, locals and temporaries one block of globals (so recursion keeps them);
  constants shared; fields with their offset globals and a vector's `_x/_y/_z`; the engine-side
  layout checked by name, type and offset, and crc 54730 written only when it matches. Every
  mistake names its file and line. The output depends on the text alone: built twice, it is the
  same bytes. `write_progs` (`file.hpp`) writes the file for it and the assembler alike.
- **`ge qc build <progs.src|file.qc> [--out=]`**: the progs and its `.lines` written, each
  diagnostic a finding at its line. `ge qc run` and the rest run a standalone program (crc 0) as
  it stands.
- **The baseline mod** (`games/shooters_edge/qc/`, its README the modder's guide): eight
  weapons (the blade, two scatterguns, two spikers, the grenade and rocket launchers, the arc
  gun), ammunition, three armours, three healths (the big one decaying), deaths, respawns,
  frags and obituaries, the frag and time limits, doors with their trigger fields, plats,
  buttons, `trigger_multiple/once/teleport/push/hurt`, drowning, lava and slime.
- **The server** (`baseline_mod.hpp`): the mod compiled from source and the arena's entity text
  for it (the arena's door and plat as models `*1` and `*2`, every weapon and item). A forced
  view (`fixangle`) is now sent once and cleared at the end of the frame, so a player turns
  after a spawn; the test mod's match digests moved with it.
- **Tests**: `progs_qc_compile_test` (every construct on the VM and its golden listing, the same

  `cli_qc_test` (the catalogue row), `shooters_edge_baseline_mod_test` (the layout check, a
