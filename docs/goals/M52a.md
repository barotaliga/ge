Status: done

Desktop mods on ABI 1.0, Shooter's Edge first (design: [`docs/mods.md`](../mods.md)).

**Built:**

- `engine/mod` (`ge_mod`, published as `ge::mod`):
  - `abi.hpp`: plain C; `ge_mod_host_v1` (the engine's libm, the game's stream, the log) and
    `ge_mod_v1` (the mod's table), each opening with `size` and `abi`; `GE_MOD_HAS`,
    `GE_MOD_EXPORT`, one exported symbol `ge_mod_entry`.
  - `manifest.hpp`: `mod.manifest` read, checked and written; `this_platform()`.
  - `sha256.hpp`: every library's hash, checked before it is opened.
  - `library.hpp`: `dlopen` on Linux and macOS, `LoadLibraryW` on Windows.
  - `loader.hpp`: the manifest, the ABI, the game and its API, the platform's file, the hash,
    the open, the entry, the table; each refusal says what failed and the next step, and an ABI
    refusal names both versions.
  - `host.hpp`: `fill_host`.
- `cmake/Mods.cmake`: `ge_add_mod`, a module library built with the engine's float flags, its
  manifest written after each build. `cmake/Fp.cmake` holds `ge_fp` and `ge_isa`, which the root
  build and a mod's own build both include.
- Shooter's Edge (`games/shooters_edge/sim/mod_api.hpp`, `mod_host.hpp`): seven hooks run after
  the game's own, the mod's functions in an entity's think or touch, the services (entities by
  number, fields by id, every argument checked and a refusal counted); the mod's block, stream
  and counts in `ModRun`, copied by a snapshot and folded into the frame's hash. A match without
  a mod keeps every hash it had.
- The sample mod `games/shooters_edge/mods/rocket_bounce` (rockets half as fast again, a
  grenade's third bounce lights its fuse).
- `ge mod new/build/check/pack`, `templates/mod-shooters_edge/`, the `mod` consumer skill and the
  `mod` skill.

**Held by:** `tests/mod_manifest_test.cpp`, `tests/mod_loader_test.cpp` (the ABI 2.0 fixture
refused, naming the version), `tests/shooters_edge_mod_test.cpp` (the match changed, replayed to
the bit, a mid-match snapshot replayed), `tests/cli_mod_test.cpp` (new, build, check, pack); the
`mod` lab and its digest row.
