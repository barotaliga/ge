Status: done

Security for an internet game, off by default so a LAN game and every plain lab send the same
bytes as before (`docs/networking.md` § Security):

- `engine/net/crypto.hpp`: XChaCha20-Poly1305 seal and open, keyed BLAKE2b key derivation, the
  per-packet nonce from a counter and the packet's type, keys from hex and from a named
  environment variable, `wipe`; Monocypher 4.0.2 (BSD-2-Clause or CC0) from its release archive
  (`cmake/Crypto.cmake`), compiled into `ge_net` and included by `crypto.cpp` alone.
- `engine/net/token.hpp`: the matchmaker's connect token (client id, two session keys, 32 bytes of
  the game's own, sealed under a key derived per host; the host id, expiry and protocol bound as
  associated data), the client's 248-byte copy, `os_random_bytes`.
- `engine/net/node.hpp`: `NodeSecurity` on a host, `node_connect_secure` on a client; the token
  carried in the handshake's padding, opened, checked for its host and expiry and used from one
  address only; accept, deny, payloads and disconnects sealed, with a 256-counter replay window;
  `NodeGuards` (per-address and global handshake buckets, a per-peer packet bucket) and
  `default_guards()`; the refusals counted in `NodeStats`.
- `engine/net/traffic_attack.hpp`: forged and stolen tokens, replayed and forged payloads, a flood
  of requests and loud clients, run beside a secure fake-traffic session.

Measured (`make lab LAB=net-link ARGS="--clients=8 --seconds=10 --secure=1"`): under every attack
at once, on every preset, all honest clients joined, every event arrived once and in order, the
round trip is the plain one within jitter (`lan` 33.3 against 33.3 ms, `bad` 237.7 against
237.4, `awful` 468.8 against 471.9), every stolen token, replay and forgery that reached the host
was refused, and the host answered no attacker. `tests/net_crypto_test.cpp` (a published
XChaCha20-Poly1305 vector), `tests/net_token_test.cpp`, `tests/net_node_secure_test.cpp` and
`tests/net_traffic_test.cpp` hold it. The `net-link` smoke digest moved: its smoke run now
includes the secure table.

Left for later rows: the matchmaker that hands out tokens (M17j's `ge-service`); the
anti-cheat's forged and replayed packet scripts on top of this (M17l); rotating a key in a long
session.
