The mod SDK shipped: `mod/abi.hpp`, `cmake/Mods.cmake` and each game's mod header installed with
the release package, so `ge mod build` needs no engine tree; the sample built and loaded on
Linux, macOS and Windows in CI; `ge mod check --run` plays the game's mod scenario with a package
and replays it. Design: [`docs/mods.md`](../mods.md) § Rows.
