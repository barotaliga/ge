Status: in progress
Milestone: **Engine mods** (`engine/mod`, `ge mod`): a game built on the engine loads mods written in C++ and built by `ge` into a distributable package, like a plugin made by a player: a stable C ABI between the game and a mod (a versioned table of functions each way, nothing of the C++ standard library across it), a manifest (the mod's name, version, the game and engine ABI it needs, its files), deterministic by contract (no clock, no random but the game's, its state in the game's snapshot so replays and prediction hold), loaded as a shared library on desktop and as a sandboxed, interpreted or ahead-of-time module where a platform forbids loading code (the App Store, Android's rules), `ge mod new/build/pack/check`, Shooter's Edge first; in rows M52a–M52e (design: [`docs/mods.md`](mods.md))
Exit: A mod built by `ge mod build` on each desktop platform changes a Shooter's Edge match and replays to the bit; a mod built against an older ABI loads or is refused with a message naming the version; the store builds load the same mod in their allowed form
Labs: `mod`

The engine's own mod format, after M18p. A mod is C++ built by `ge mod build` against the
engine's mod ABI into a package (a manifest and one library or module a platform), loaded by
any game on the engine that offers mod hooks. The design and every decision with what was
considered and not taken: [`docs/mods.md`](../mods.md).
