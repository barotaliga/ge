Status: in progress

The multiplayer mods' server was built in a clean room from the written specification
(`porting/shooters-edge/builtins.md`, with `progs.md`, `gameloop.md`, `movement.md` and
`protocol.md`). The building session never read an existing server, VM or mod source.

**Built:**

- **The standard builtins that touch no world** (`plugins/progs/stdlib.hpp`):
  - the maths (with `sin`, `cos`, `sqrt` and `pow` through `core/libm`), the vectors, and
    `random` and `randomvec` from the game's seeded generator;
  - `ftos` and `vtos` (`text.hpp`: the shortest form that reads back, and the exponent form at
    or past 1e21), `stof`;
  - `tokenize`, `argc` and `argv`; the string extensions and `strzone` (1024 zone slots).
  - A builtin's text result lives in a ring of 64, apart from the hooks' ring of 8.
- **The map's entity text** (`plugins/progs/entity_text.hpp`):
  - parsed into the progs' own fields by their declared types;
  - `angle` and `light` renamed, `_` keys skipped, an unknown key skipped with a message;
  - the inhibit flags (not in deathmatch);
  - each block's spawn function called, and a block with none removed with a message.
- **The mod server** (`games/shooters_edge/server`, in the `shooters_edge_server` library beside
  the host):
  - `catalogue.hpp`:
    - every standard number 1–82 and every extension builtin by number;
    - the extensions `checkextension` answers yes for, as one table;
    - an install that refuses a row past the VM's table, which is now 1024 wide.
  - `bi_world.cpp`, `bi_monster.cpp`, `bi_message.cpp` and `bi_settings.cpp`: the game's
    builtins over the loop.
    - World: traces, `find`/`findradius`, `checkclient`, `aim`, `droptofloor`, `makestatic`.
    - The monster moves: `walkmove`, `movetogoal`, `checkbottom`, `changeyaw`.
    - Prints and sounds.
    - The Write family and `multicast` (`messages.hpp`).
    - Precaching, cvars, `infokey`, `logfrag`, `calltimeofday`, `setpause` and
      `precache_vwep_model`.
  - `qc_server.hpp`:
    - the hooks around the loop: StartFrame, the thinks, SetNewParms and SetChangeParms,
      ClientConnect and ClientDisconnect, the spectator hooks, and the time-of-day hook;
    - the extension fields (alpha, colormod, maxspeed, gravity, movement, vw_index, items2,
      trackent), mirrored both ways;
    - clients with user info and spawn parms; maps loaded from entity text; error and objerror
      stopping the map; changelevel.
  - `commands.hpp`: UserCmd and GE_ClientCommand, ChatMessage, UserInfo_Changed, the console
    (ConsoleCmd, localinfo), and pausing (GE_PausedTic, GE_ShouldPause).
  - `test_mod.hpp`: an assembled deathmatch mod with rockets, frags, logfrag, a time limit,
    UserCmd and ChatMessage, and the arena's entity text.
  - `mod_match.hpp`: a progs loaded from a path (`--progs`, else the `sv_progs` cvar, else the
    test mod), with its `.lines` table beside it. Bots play it on the test arena to its time
    limit, and every frame gets a digest.
- **The loop's settings a QC server needs** (`plugins/shooter`):
  - `first_dynamic` (33);
  - a full pool reusing the last entity;
  - the command's movement on the entity.
  - All default off, so the native program's digests do not move.
- **Held by** 87 checks in 9 new test files (31 progs and shooter tests in all, all green):
  - `tests/progs_text_test.cpp` (7);
  - `tests/progs_stdlib_test.cpp` (9; golden `tests/golden/progs_stdlib.txt`);

  - `tests/shooters_edge_qc_monster_test.cpp` (7; golden `tests/golden/shooters_edge_qc_monster.txt`);
  - `tests/shooters_edge_qc_hooks_test.cpp` (11);

  - `tests/shooters_edge_mod_match_test.cpp` (8; golden `tests/golden/shooters_edge_mod_match.txt`:

- **The `se-mod` lab** (`games/shooters_edge/labs/se_mod_lab.cpp`, in `make labs-smoke`):

    (3 frags net of suicides) and 0 faults.

**Choices where the spec was open:**

- The Write family's encodings are ours, because `protocol.md` has none yet. Effects are kept
  as typed events.
- With no visibility or hearing data, every point is in every set (M18b brings the map's
  sets).
- `trackent` is read as an entity value.
- Spectators: the user-info key `sp` and the `sv_specprint` bits.
- FL_NOTARGET is 128 and FL_PARTIALGROUND is 1024.
- Angles wrap on the 16-bit grid.
- Entity text: a backslash before another character is kept and the character dropped.
- `tokenize`: the 1024-byte budget counts terminators. The arguments line runs to the end of
  the line. `argc`/`argv` read the command's words during UserCmd and ConsoleCmd.
- The date `calltimeofday` hands the hook is in the hook ring of 8. The long frag log uses the
  same date text.
- `precache_vwep_model` returns a 0-based index.
- `netname` is set at connect (before SetNewParms) and on a `name` change.
- `bprint` does not filter by level; the level is recorded.
- There is no lag compensation, so the compensated traceline and the history reset do nothing.
- A `map` console line only records the pending map.
- `ftos` at or past 1e21 uses the shortest exponent form.
- `substr`'s negative start and length rules, and `rint` adding the half in double.
- A respawn the mod calls from QC is not a hook, so the report counts deaths from the frag log.

**Left open:**

- A player's own competitive mod on a free map. The brush plugin (M18b) brings the free maps
  and their visibility sets. No mod is committed, so a real mod is run by a player
  (`docs/shooters-edge.md` § Running your own mod).
- The wire encodings, once `protocol.md` states them (M18g).
- The dedicated server (`shooters_edge_server`, M18f) taking the same `--progs` and `sv_progs`,
  and `ge server`.
