Labs: `se-gallery`

Built:

- `engine/capture/gallery.hpp`: `Gallery` lists a folder's stills newest first by the time in
  their names (`list_stills`, `taken_of`), pages them in the cells a game's layout fits
  (`set_grid`, `gallery_cells`), takes a frame's presses in three modes (grid, viewer, confirm)
  and says what they did, deletes the selected file after asking (never anything but a still in
  its folder), and loads thumbnails and full pictures on a worker thread of its own, most wanted
  first, letting go of what is far away. `poll` lists the folder again when it changes.
- `ui::Image::revision`: the GPU's 2D pass uploads an image again when it moves, so a texture
  whose pixels change (a gallery's slot) is redrawn; it used to be uploaded once per address.
- `platform::Key::del` and `backspace`; `ui::MenuInput::del`.
- Shooter's Edge: OPTIONS > SCREENSHOTS (`menu_screenshots`), `menu/gallery_page.hpp` drawing the
  grid, the viewer, the delete's question and the empty folder in the modern menu's look; the
  window names the folder F12 writes to.
