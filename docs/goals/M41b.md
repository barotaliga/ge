Milestone: **Rebaked light in the cache**: the lightmap stage hands each map to `brush::rebake_map` (M40b) with the enhanced albedo and the map's lights, and writes its GERB file
Exit: Every shareware map rebaked into the cache; the stage keyed so a rebake version bump reruns it
Labs: `enhance`, the lightmaps lab

The lightmap stage calls `brush::rebake_map` (M40b, `plugins/brush/rebake.hpp`) with the enhanced
albedo (`texture_means`) and the map's lights (`bake_lights`), sky colour from the map, and writes
`lightmaps/<map>.gerb` (`write_rebaked`, light direction in world space). `kLightmapStageVersion`
moves to 2 so every cache reruns the stage.
