Status: in progress

Built: the console as the 2D layer's draw list (`engine/ui/console.hpp`, `draw_console`): the
panel at the view's cover on the con_bg* gradient (and con_bgimage's picture, when the caller
loads it), the edge, the lines in their kinds' colours, the input line with the hint and a
blinking cursor, the suggestions under the edge with the selected row lit, and the notify lines
when it is up; sizes at a 720 px reference, the look a `ConsoleStyle`. The `console` lab draws
it through the CPU raster.

Built: the console in Fall Line's window. `ui::feed_console` (`engine/ui/console_keys.hpp`)
feeds a frame's key and text events to the binds (HID usages as bind names,
`console::usage_key`, with the held modifiers) and to the view's input line (the edit keys and
their repeats, the typed text); the tilde opens and closes it, Escape closes it, and the run reads
no keys while it is down. Fall Line's frame draws the 2D pass after post (the `ui` row,
`FrameScene::overlay`), and the `world` lab's `console` still shows it down over the game's frame.

Open: con_font picks a charset once the charsets (M27a) are fonts a text run can name; con_bgimage
is drawn once the game loads its picture (the cvar is read, the image is not yet loaded).
