Exit: JOIN A GAME hides full or empty servers, shows one mode and drops servers past a ping bound, each a sb_ cvar kept in the player's config and toggled by a key on the page; the se-browser lab walks each filter
Labs: `se-browser`

The page (`games/shooters_edge/menu/servers_page.hpp`) passes the engine's `ServerFilter`
(`engine/net/server_list.hpp`, which already had the filters) four cvars, each kept with the
config (`kArchive`) and stepped by a key the page reads from `MenuInput::letter`, a letter key
tapped that a page claims as its own (the window sets it for E, F, M and P):

- F: `sb_hidefull`, the servers with every slot taken hidden;
- E: `sb_hideempty`, the servers nobody plays on hidden;
- M: `sb_mode`, the next of the modes the answered servers name (A to Z, then every mode);
- P: `sb_maxping`, the next bound of 50, 100, 150 and 250 ms, then any.

A key sets the cvar through the console, so the choice is the same as typing it and is saved with
the config. The title row adds what is on and how many answered servers it hides
("NOT FULL OR EMPTY, TEAM ONLY, PING UNDER 50 (6 HIDDEN)"; the classic look's foot "7 servers, 6
hidden"), and a list the filters empty says EVERY SERVER FILTERED OUT with the keys to change them,
not "no servers found". The keys line names F/E/M/P.

Held by `tests/shooters_edge_menu_test.cpp` (three servers on the simulated network, each filter
by key and by the console, every server filtered out drawn at two sizes) and walked by the
`se-browser` lab (`hide-full-empty`, `ping-bound`, `team-only` at both viewports, the hidden
counts as metrics, no layout problems).
