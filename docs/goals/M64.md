## How a round plays

- **The window, headless.** `xvfb-run -a se -classic q1|q2 -basedir <install> -recipes -config
  <own.cfg> -logfile <log> --size=480p +set ce_auto 0 +map <map> +exec <recipe.cfg>`: a recipe
  (`window-recipes` skill) sleeps, presses, lists menu pages, takes screenshots and dumps the
  console. Software rendering makes every frame slow (about 2 fps at 480p), so a frame's time
  says nothing about a GPU; a freeze of seconds on the CPU still shows as the run's longest frame.
- **A server and its bots.** `sesv --root=<install> --map=<map> --port=<p>` with `sebots
  --server=127.0.0.1:<p> --basedir=<install>`: the bots' nav line says how long the map took them
  and its hash.
- **Sampling a freeze.** `gdb -p <pid> -batch -ex "bt 40"` once a second while it lasts names
  what the main thread is doing.

## Severity

1. A crash, a hang, or a game that cannot be played (cannot start, join or load a map).
2. A freeze of a second or more, a feature that does not work, a wrong result a player sees.
3. A wrong detail a player notices, a misleading message.
4. A tool or an agent's run (not a player's) that misbehaves.
