Milestone: **The native protocol: our client and our server over engine/net's node (handshake, AEAD, NAT traversal) and replication, beside the classic one on the same port**
Exit: Our window joins our server natively and plays as on the classic protocol, a classic client on the same server at once; entities on M17f's snapshots; every condition preset held by se-net
Labs: `se-net`

Split out of M18h, whose list named it last (2026-11-25). The design: gameplay never knows which
protocol a client speaks. The rules, the server's frame and the classic game stream (signon, the
svc messages a mod writes byte by byte, the frames) stay one; the native protocol changes what
carries them and, slice by slice, replaces the parts of the classic stream the engine does better.

The slices, each its own pull request:

1. **The native link (built, this PR).** `engine/net`'s node carries the game's own datagrams on one
   of its channels (a tunnel any game with an older protocol can use), with datagrams that are not
   the node's passed through (`keep_foreign`), so one port serves both. Shooter's Edge's
   QuakeWorld server runs a node over its socket and hands the classic endpoint both kinds of
   client through one pipe; the window joins natively where the server says it can (its
   serverinfo), else classically. Held by a test with both kinds of client on one server, and the
   native client's moves predicted as before.
2. **Secure joins.** The node's connect tokens (M17i) from a ticket the master hands a logged-in
   player (M59), so every native packet is sealed and a token from elsewhere is refused.
3. **Entities on snapshots.** The players and entities sent as M17f's quantized rows with deltas
   against the acked snapshot and interest, in place of the classic packet entities; the window
   reads them into the same drawn state.
4. **Moves on the replication inputs.** The moves sent with redundancy and time sync (M17n), the
   server's slack told back; lag compensation by rewind (M17q) for hitscan where the rules allow.
5. **NAT traversal.** A listen server behind a home router joined through the rendezvous and hole
   punching, the relay when that fails (M17e).
6. **Every preset held.** `se-net` runs each condition preset on both protocols and charts
   corrections, bytes and delay side by side.
