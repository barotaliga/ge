Status: in progress
Milestone: **Modern features**: voice on the native protocol (M17h), skeletal models beside MDL, data-driven particles, replacement textures, the common QC extensions
Exit: Each feature pictured or measured on a free map
Labs: each feature's: `gpu-particle-effects`, `se-timedemo`

**Replacement textures**: built (`client/game_adapter.hpp`'s `map_textures`: a PNG or TGA in the
game's files stands in for a map's texture by its name).

**Data-driven particles**: built. An effect is a few lines of text (`engine/particles/effect.hpp`:
bursts and trails, their shape, speeds, life, size, fall, colour or palette run, shine or smoke,
cooling, growth, streaks, bounce, a light), read whole or refused with its file, line and fix;
Shooter's Edge reads `particles/*.fx` from the game's files and throws an effect named for a
classic one in its place (`client/world_fx.hpp`). Held by `tests/particles_effect_test.cpp`,
the `gpu-particle-effects` lab (a sample book on the yard, the faults' table) and the
`se-timedemo` lab's `--particles=sample`.

**Skeletal models**: read. `engine/assets/iqm.hpp` reads a mod's `.iqm` (version 2: joints,
meshes, blend weights, animations) into the engine's `Model`, so it poses and skins as an
authored model does, and writes one back. Held by `tests/assets_iqm_test.cpp` (a round trip, the
frame, the winding, a file without joints, the faults) and the `models` lab's `--format=iqm`;
checked by hand on a real exported file (75 joints, one clip) through `--model`. **Drawn in the
game**: a model the server names as `.iqm` (or a file starting with the skeletal magic under any
name) is posed through each clip at 20 a second into a morph model's frames, a clip a frame group
(`plugins/morph/skeletal.hpp`), its materials' pictures one skin, and drawn by the window's model
pass as a classic model is (floor light, both looks, frame blending, warps, glows). Held by
`tests/morph_skeletal_test.cpp`, `tests/shooters_edge_game_adapter_test.cpp` and the `se-models`
lab's `--models=iqm`.

**A mod's own effects**: drawn on the listen server. `DP_SV_POINTPARTICLES`
(`server/catalogue.hpp`): `particleeffectnum` (#335) gives a name its number, `pointparticles`
(#337) and `trailparticles` (#336) send the effect by its name to those who see it
(`server/messages.hpp`'s `point_effect` and `trail_effect` events). The window draws an effect of
a classic name (`gunshot`, `te_explosion`, ...) as the classic effect, any other as the game's
files' effect of that name (`particles/*.fx`), or nothing when they define none; a classic client
gets the temporary entity of a classic name and nothing for any other (never a message it does
not know). Held by `tests/shooters_edge_qc_messages_test.cpp`, `tests/shooters_edge_listen_test.cpp`
and the `se-weapon-fx` lab's `--mod-effects=1`.

Next in this row: a mod's own effects sent to a remote client of the game's own over the wire (an
extension the challenge offers, so a classic client never sees it), voice on the native protocol
