Labs: `save-run`

Built:

- `Run::save(save::FileWriter&) const` and `Run::load(save::FileReader&, error)` on the play
  contract (`engine/play/game.hpp`); a game with no saves returns false.
- `engine/play/saves.hpp`: `save_run` (the meta with the setup as the input log's header, the
  `PLAY` chunk with the step, then the game's chunks), `load_run` (the setup read back, the run
  opened on it and loaded), and `check_saves`: a log played straight, saved at the steps asked,
  each save loaded into a run already played on 360 steps (so a field left out of a describe
  keeps a wrong value instead of a lucky default) and stepped beside the straight run's digests
  to the log's end, where the two must also save to the same bytes.
- `describe` beside every state type the run holds: the skier, the snowmobile, the helicopter
  and the paramotor plugins (`plugins/*`), the mountain's `Track`, `racing`'s tape recorder,
  the bots' layer (`engine/ai`: hands, memory, steering), `core::Quat`/`Vec3`, and Fall Line's
  own (the state, the crowd, the army, the gunfire, the wanted level, the bot's plan and hands,
  the Driver). `io.hpp` gained bounded C arrays and `shared_ptr` (saved as its own copy).
- Fall Line's run in two chunks: `DRVR` (the Driver) and `PILT` (the pilot's hands and the
  events the agent has not yet been told).
- `play save write|load|check|diff` and `ge save write|load|check|diff`.

Measured (release, the container):

- `tests/play_saves_test.cpp`: seed 38's whole race (29,538 steps alone; a field of four on human
  hands), saved at steps 0, 1, 600, half-way, 5 before the end and the end: no save parts from
  the run never saved. With one field (`yaw_rate`) taken out of the skier's describe, every save
  from step 1 on parts on its next step.
- The `save-run` lab, 120 s a scene saved every 10 s: race, free ride (the crowd dealt, down a
  run, up a lift, down again), snowmobile, helicopter, paramotor: 65 saves, 0 parted, 0 ends
  differ. A save is 37–155 KB, written in 0.04–0.25 ms and read back in 0.05–0.19 ms (the
  crowd's 110 KB is the free ride's largest part; the bot's plan the race's). Building the map a
  load's setup names takes 290 ms (the race) and 1,319 ms (the free ride): the load's cost is
  the map's, which M25h's content cache is for.
- `ge save load` of a save made 60 s into seed 38's race, played on by the pilot to the end,
  reaches the digest of the run never saved (`bbba828d57e45bfa`).
