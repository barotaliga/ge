# Reserved roadmap rows

the same number twice. A row leaves this table in the pull request that adds it to
[`../goals.md`](../goals.md).

| Row | What |
| --- | --- |
| M27 | **Bitmap font charsets** |
| M28 | **Character movement physics** |
| M43 | **Eye adaptation**: the exposure follows what the eye sees, metered off the frame, adapting over seconds from a dark hall into daylight and back |
| M44 | **Room acoustics**: a reverb whose size, decay and early echoes are probed from the level's own structure round the listener |
| M45 | **Vertex animation interpolated**: frame-to-frame blending of vertex-animated models so they move smoothly at any frame rate |
| M46 | **Sound cleanup**: an offline denoise and declick a game's imported sounds pass through |
