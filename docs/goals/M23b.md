Status: done

Built (PR "replays: the replay file, the index and the instant replay"):

- `engine/play/game.hpp`: `GameSpec::version`, the game's behaviour version, raised by a change
  that moves what a log plays to.
- `engine/replay/file.hpp`: the replay file (`*.ge-replay`): the input log with marks (step, kind,
  weight), a clip's in and out, the game's version and the app's date as text; `plays_on` refuses
  another version naming both; save and load.
- `engine/replay/index.hpp`: a directory's replay files as list rows (game, version, seed, length,
  marks and their kinds, clip, date), a broken file a problem line.
- `engine/replay/live.hpp`: the live run as a session that keeps keyframes and marks (back-dated
  or not); the instant replay lent the live keeper (moved, not copied) and handed back; the
  player adopting a keeper starts from its copy of the run as opened, so no run is opened again.

Measured by the `replay-file` lab (seed 38, three rivals with human hands, the whole race of
246 s, an instant replay of the last 30 s every 30 s, debug build): 8 instant replays and a clip
of 8 s round the heaviest mark, every step of each checked against the live race, 0 mismatches,
and the live race resumed to the same digest each time; the file reads back to the same text
and the game one version on refuses it naming both versions; an instant replay lands in at most
7.5 ms; the file is 388 KB for the race (95 KB a minute: the bot's analogue steering moves every
step, so the run-length log is a line a step).
