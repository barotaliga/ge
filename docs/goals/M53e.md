Milestone: **Meta-cvars** (`engine/console`): a cvar whose levels set groups of others, declared as data beside the feature that owns it; explicit beats implied whatever the order; turning one off restores its members to the layers under it; a level including another meta-cvar's level, a cycle refused at declaration naming the loop; `--explain`, `cvarlist` and `help` show them; the first, `sv_modern`, over the network's modern settings
Exit: A golden fixture holds the precedence (a cfg's explicit value survives a meta-cvar run before or after it), restoring, nesting and the refused cycle
Labs: `server-cfg`

Design: [`docs/servers.md`](../servers.md) § Meta-cvars.

- Built: `Cvars::add_meta` and the `meta` command (engine/console/cvar.hpp § META-CVARS): each cvar
  keeps the value under the metas (`below`), the meta that set it (`implied_by`) and whether
  anything explicit set it; a meta's level fills only what is not explicit, a level that leaves a
  member out restores it, a latched member waits for `apply_latched`, includes open in place and a
  loop is refused at declaration with the loop named. `help`, `cvarlist` (`[meta]`, `[by <meta>]`)
  and `--explain` (`sv_quick 1 (over the fallback "5")`) show them; `cfg_save` writes the value
  under a meta. Held by the `meta-*` fixtures in `tests/golden/console_script.txt`, and by
  `console_cvar_test`, `console_console_test`, `net_cvars_test` and `server_cfg_test`.
- `sv_modern` beside the network's cvars (`engine/net/net_cvars.cpp`): 1 `sv_fps 120;
  sv_maxupdaterate 120; sv_rewindmax 0.2`; 2 includes 1 with `sv_maxrate 0; sv_rewindmax 0.1`. The
  `server-cfg` lab switches it on in a mod over a base that set `sv_fps 77`, which stands.
